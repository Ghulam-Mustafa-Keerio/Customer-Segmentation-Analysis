# Repository Configuration Notes

This file contains instructions for repository settings that need to be updated manually through the GitHub web interface.

## 📝 Repository Description

Update the repository description to:

```
Comprehensive customer segmentation analysis of Istanbul shopping data using RFM analysis and clustering algorithms. Delivers actionable insights for targeted marketing and business strategy. Perfect for data analysts and ML enthusiasts.
```

**How to update:**
1. Go to the repository page on GitHub
2. Click on the "⚙️ Settings" gear icon (top right, near "About" section)
3. Edit the "Description" field
4. Click "Save changes"

## 🏷️ Repository Topics

Add the following topics to the repository:

- `customer-segmentation`
- `data-analysis`
- `machine-learning`
- `clustering`
- `rfm-analysis`
- `business-intelligence`
- `data-science`
- `python`
- `retail-analytics`
- `customer-analytics`

**How to add topics:**
1. Go to the repository page on GitHub
2. Click on the "⚙️" gear icon next to "About" section
3. In the "Topics" field, add each topic (comma-separated or press Enter after each)
4. Click "Save changes"

## 📄 License

The repository now has a LICENSE file (MIT License). GitHub should automatically detect it.

**Verify:**
1. Go to repository page
2. Check if "MIT License" appears in the right sidebar
3. If not detected, go to Settings → scroll to "License" section → select "MIT License"
